## The font needs a decision before this goes public

`core/tc_font.h` is generated by `tools/mkfont.py` from the console font shipped
in Debian/Ubuntu's `kbd` package — the IBM VGA ROM face. Two things are true and
in tension:

- Typeface *designs* are not copyrightable in the US, and plain bitmap
  representations are generally treated the same way; this font has been
  redistributed everywhere for decades.
- The `kbd` package itself is GPL-2, and the PSF file arrives under that
  umbrella. Whether that reaches a generated bitmap table is not something to
  guess at.

While this repository is private it does not matter. **Before making it public
or shipping a binary to Universal-DB / the Homebrew Browser, either confirm the
above or regenerate from a font with an unambiguous licence** — `mkfont.py`
takes any PSF1 file as its argument, so swapping is a one-command change:

    python3 tools/mkfont.py /path/to/some-other-font.psf.gz
